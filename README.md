# Free Telegram Radars Runner

Обезличенный публичный движок двух Telegram-радаров. Он запускается бесплатно
по расписанию GitHub Actions:

- поиск свежих фриланс-заказов — каждые 5 минут;
- поиск выгодных билетов — каждые 45 минут;
- обработка команд обоих Telegram-ботов — во время ближайшего запуска.

В репозитории нет токенов, Telegram-ID, имени владельца, контактных данных,
рабочих баз и логов. Все персональные значения хранятся только в зашифрованных
GitHub Actions Secrets. Состояние SQLite хранится в закрытом Actions Cache и не
публикуется вместе с кодом.

Публичность нужна только для бесплатных стандартных GitHub-hosted runners.
Ежемесячное техническое обслуживание поддерживает расписания активными.
