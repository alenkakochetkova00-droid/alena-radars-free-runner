# Радар заказов для Алёны

Бот каждые 3 минуты проверяет открытые источники с фриланс-заказами и присылает в Telegram только заявки, которые проходят фильтры:

- объявление свежее;
- в тексте есть публичный Telegram, телефон или email заказчика;
- указан бюджет;
- бюджет выше расчётной рыночной цены;
- работа соответствует направлениям: карточки WB/Ozon, баннеры, логотипы и упаковка, Tilda, сайты и тексты;
- расчётная ставка не ниже 1 800 ₽ в час;
- объявление не похоже на отзывы, выкупы, криптоарбитраж или схему с предварительным взносом.

В каждом уведомлении бот показывает исходное задание, бюджет, предлагаемую цену, примерную трудоёмкость, контакт и готовый ответ от женского лица.

## Подключённые источники

- публичные Telegram-каналы `@designwork_vacansii`, `@GetClient`, `@digitaltender`, `@design_freevacancies`, `@zakaz_design`, `@freelancechoice`;
- открытая лента Weblancer;
- открытая лента FreelanceJob.

Бот не обходит подписки, авторизацию и платные отклики. Скрытые контакты он не добывает — используются только данные, которые заказчик опубликовал сам.

## Как запустить

1. В Telegram откройте официального `@BotFather`.
2. Отправьте `/newbot`, придумайте название и username.
3. Скопируйте полученный токен.
4. В папке бота скопируйте `.env.example` в `.env` и вставьте токен после `TELEGRAM_BOT_TOKEN=`.
5. Для проверки выполните:

   ```bash
   python3 order_radar.py --test
   python3 order_radar.py --dry-run
   ```

6. Запустите `./run.sh`, найдите созданного бота в Telegram и отправьте ему `/start`.

Для постоянной работы на Mac выполните `./install_macos.sh`. После этого радар запускается вместе с компьютером и автоматически перезапускается после сбоя. Mac должен быть включён и подключён к интернету.

## Команды

- `/status` — состояние и дневная цель;
- `/goal 10000` — поменять цель;
- `/done 2500` — отметить полученный заработок;
- `/pause` и `/resume` — остановить или возобновить уведомления;
- `/test` — получить демонстрационную карточку.

## Настройка фильтров

Все параметры находятся в `config.json`:

- `poll_interval_seconds` — частота проверки;
- `max_age_minutes` — максимальный возраст заказа;
- `minimum_budget_to_market_ratio` — насколько бюджет должен быть выше рынка;
- `minimum_effective_hourly_rub` — минимальная расчётная ставка;
- `require_public_contact` — присылать только заявки с открытым контактом;
- `require_budget` — пропускать объявления без указанной суммы.

Рыночные цены по категориям также находятся в `config.json` и могут быть изменены без правки программы.
